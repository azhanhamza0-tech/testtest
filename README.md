# مەرزە موڤیز (Merze Movies) - سەکۆی پێشکەوتووی ستریمینگی کوردی

بەخێربێن بۆ پڕۆژەی فەرمیی **مەرزە موڤیز (Merze Movies)**؛ سەکۆیەکی تەواوی ستریمینگی سینەمایی مۆدێرن بە زمانی شیرینی کوردیی سۆرانی (RTL) لەگەڵ دیزاینی سەرسوڕهێنەری سینەمایی، بەستنەوەی ڕاستەوخۆ بە داتابەیسی هەوری **Firebase (merzemovies)**، سیستەمی بەشداریکردنی زێڕینی VIP بە کارتی QI Card، و کۆنتڕۆڵ پەنێڵی تەواوی بەڕێوەبەرایەتی.

---

## ناوەڕۆک و ڕێبەری هەمەلایەنەی پڕۆژە (٢٠ بەش)

### ١. چۆنیەتی دامەزراندنی پڕۆژە (Installation)
پڕۆژەکە بە تەواوی ئامادەیە لە بوخچەی:
`C:\Users\pc\.gemini\antigravity-ide\scratch\merze-movies`
دەتوانیت ئەم بوخچەیە بکەیتەوە لەناو ئیدیتەرەکەت (وەک VS Code یان Antigravity IDE) و دایبنێیت وەکو Workspace ی سەرەکی.

### ٢. چۆنیەتی دامەزراندنی پێداویستییەکان (Dependencies)
پڕۆژەکە لەسەر بنەمای تەکنەلۆژیای مۆدێرنی وێب داڕێژراوە و هەموو کتێبخانەکانی پێویست (Firebase App, Auth, Firestore, Storage) لە ڕێگەی CDN ی خێرای گووگڵەوە ڕاستەوخۆ باردەکرێن، هەربۆیە پێویست بە هیچ دانانێکی قورس یان پاکێجی دەرەکی ناکات.

### ٣. چۆنیەتی دروستکردنی داتابەیسی PostgreSQL یان Firebase
پڕۆژەکە بە شێوەیەکی بنەڕەتی بە داتابەیسی ڕاستەقینەی هەوری **Firebase** بەستراوەتەوە:
* **Project ID:** `merzemovies`
* **Auth Domain:** `merzemovies.firebaseapp.com`
* **Firestore:** کۆلێکشنەکانی `movies`، `series`، `payments`، `settings`، و `users` بە شێوەی خۆکار لەگەڵ یەکەم کردنەوەدا دروست دەبن و ئامادە دەکرێن.
* بۆ بەکارهێنانی PostgreSQL ی دەرەکی لە داهاتوودا، دەتوانیت نموونەی `.env.example` بەکاربهێنیت.

### ٤. چۆنیەتی ڕێکخستنی پەڕگەی `.env`
پەڕگەی `.env.example` کورتەی هەموو گۆڕاوە ژینگەییەکان لەخۆدەگرێت. دەتوانیت پەڕگەیەکی نوێ بە ناوی `.env` دروست بکەیت و زانیارییەکانی تێدا دابنێیت:
```env
FIREBASE_API_KEY="AIzaSyAvL1WKP1hnG0Uv-_gojBOH6rLDYhx8RYA"
FIREBASE_PROJECT_ID="merzemovies"
VIP_MONTHLY_PRICE_IQD=5000
```

### ٥. چۆنیەتی جێبەجێکردنی کۆچاندنی داتابەیس (Migrations)
پەیکەری داتابەیس لە ڕێگەی پەڕگەی `js/db.js` بە تەواوی ڕێکخراوە و لە کاتی گۆڕانکاری لە ستوون یان داتاکان، خۆکار نوێدەبێتەوە بەبێ پێویستی بە تێکدانی داتاکانی تر.

### ٦. چۆنیەتی چاندنی داتای سەرەتایی (Database Seeding)
پەڕگەی `js/seed-data.js` کۆمەڵێک فیلمی بەناوبانگی کوردی (وەک بێکەس، کیسەڵەکانیش دەفڕن، پەڕەسێلکە) و فیلم و زنجیرە جیهانییەکان (وەک ئۆپنهایمەر، دیوون، گەیم ئۆف سرۆنس بە وەرز و ئەڵقەکانەوە) لەخۆدەگرێت. لە یەکەم کردنەوەی ماڵپەڕدا سیستمەکە پشکنین دەکات و ئەگەر داتابەیس بەتاڵ بێت دەستبەجێ بە داتاکان پڕی دەکاتەوە.

### ٧. چۆنیەتی کارپێکردنی ڕاژەکاری گەشەپێدان (Dev Server)
سکریپتی خێرای `server.ps1` ئامادەکراوە بۆ کارپێکردن لەسەر پۆرتی ۳٠٠٠ بە فەرمانی PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
پاشان لە وێبگەڕەکەتدا بچۆ بۆ:
`http://localhost:3000`

### ٨. چۆنیەتی دروستکردنی وەشانی بەرهەمهێنان (Production Build)
ماڵپەڕەکە بە شێوازی کێش سووک و خێرا (Optimized Single Page Architecture) دروستکراوە و هیچ پرۆسەیەکی درێژی Build ی پێویست نییە؛ بە دانانی فایلەکان لەسەر هەر وێب هۆستێک (وەک Firebase Hosting, Vercel, Netlify, یان Apache/Nginx) دەستبەجێ کاردەکات.

### ٩. چۆنیەتی دروستکردنی یەکەم هەژماری بەڕێوەبەر (Admin Account)
سیستەمەکە هەژمارێکی فەرمیی ئەدمینی بە شێوەی ئامادەکراو تێدایە:
* **ئیمەیڵ:** `admin@merzemovies.com`
* **وشەی نهێنی:** `admin123`
بە چوونەژوورەوە لە ڕێگەی ئەم هەژمارە، دوگمەی **"🛠️ بەڕێوەبەرایەتی"** لە سەرەوەی ماڵپەڕەکەدا دەردەکەوێت.

### ١٠. چۆنیەتی زیادکردنی فیلمی نوێ (Add Movie)
1. بچۆ ناو بەشی **بەڕێوەبەرایەتی** لە سەرەوەی ماڵپەڕ.
2. کلیک لەسەر دوگمەی **"زیادکردنی فیلمی نوێ"** بکە.
3. زانیارییەکان پڕبکەرەوە: ناونیشان، ساڵ، نمرە، جۆری پاکێج (بێبەرامبەر / VIP)، کورتەی کوردی، بەستەری پۆستەر و باکدراپ، بەستەری ترەیلەر، و بەستەری ڤیدیۆ بە کوالیتی 1080p.
4. دوگمەی **"زیادکردنی فیلم"** دابگرە تا دەستبەجێ بچێتە داتابەیس و لە پەڕەی سەرەکی دەربکەوێت.

### ١١. چۆنیەتی دەستکاریکردنی فیلم (Edit Movie)
لە بەشی بەڕێوەبەرایەتی، لە تابی **فیلمەکان**، کلیک لەسەر دوگمەی **"دەستکاری"** ی تەنیشت هەر فیلمێک بکە بۆ گۆڕینی زانیاری و نوێکردنەوەی.

### ١٢. چۆنیەتی سڕینەوەی فیلم (Delete Movie)
لە بەشی بەڕێوەبەرایەتی، لە تابی **فیلمەکان**، دوگمەی **"سڕینەوە"** دابگرە. سیستمەکە بە نامەیەکی کوردی داوای دووپاتکردنەوە دەکات بۆ ئەوەی بە هەڵە فیلم سڕینەوە ڕوونەدات.

### ١٣. چۆنیەتی زیادکردنی زنجیرە (Add Series)
لە بەشی بەڕێوەبەرایەتی، کلیک لەسەر تابی **زنجیرەکان** بکە و دوگمەی **"+ زنجیرەی نوێ"** دابگرە، ناونیشانی کوردی، پۆستەر، ساڵ، و کورتەکەی دیاریبکە.

### ١٤. چۆنیەتی زیادکردنی وەرز و ئەڵقەکان (Add Episodes)
هەر زنجیرەیەک دەتوانێت چەندین وەرزی هەبێت. لەژێر هەر وەرزێکدا دەتوانیت ژمارەی ئەڵقە، ناونیشانی ئەڵقە بە کوردی، کورتە، وێنۆک (Thumbnail)، و بەستەری ڤیدیۆی ئەڵقەکە دابنێیت.

### ١٥. چۆنیەتی گۆڕینی QR Code ی پارەدانی کی کارت
1. لە کۆنتڕۆڵ پەنێڵی ئەدمین بچۆ بۆ تابی **"ڕێکخستنی QR و پارەدان"**.
2. بەستەری نوێی وێنەی QR Code لە خانەی دیاریکراو بنووسە یان بیگۆڕە.
3. دەتوانیت بڕی پارە (٥,٠٠٠ دینار) و دەقی ڕێنمایییەکانی پارەدانیش دەستکاری بکەیت.
4. دوگمەی پاشەکەوتکردن دابگرە؛ دەستبەجێ لە پەڕەی VIP بۆ هەموو بەکارهێنەران وێنە نوێیەکە پیشان دەدرێت و بە هیچ جۆرێک هاردکۆد نەکراوە.

### ١٦. چۆنیەتی پەسەندکردنی پارەدانی بەشداربووانی VIP
1. بەکارهێنەر لە پەڕەی VIP پارە دەنێرێت بە کارتی QI و ژمارەی پسوولە (Transaction ID) و وێنەکەی دەنێرێت.
2. لە پەنێڵی ئەدمین، لە تابی **"داواکارییەکانی پارەدان"** لیستی داواکارییە چاوەڕوانکراوەکان (Pending) دەبینیت.
3. بە کلیک لەسەر **"بینینی پسوولە"** سەیری وێنەکە بکە و دڵنیابەرەوە لە ژمارەی مامەڵەکە.
4. کلیک لەسەر **"پەسەندکردن" (Approve)** بکە. دەستبەجێ داتابەیسەکە هەژماری بەکارهێنەرەکە دەکاتە **VIP** بۆ ماوەی یەک مانگ (٣٠ ڕۆژ).

### ١٧. سیستەمی بەسەرچوونی VIP چۆن کاردەکات؟
کاتی پەسەندکردن، بەرواری بەسەرچوون (`vip_expires_at`) تۆمار دەکرێت بۆ ۳٠ ڕۆژ لە ڕۆژی پەسەندکردنەوە. هەر کات بەروارەکە گەیشتە کۆتایی، لۆجیکی سێرڤەر و دەسەڵاتەکان هەژمارەکە دەگەڕێنێتەوە بۆ **FREE** و سنووردارکردنەکان سەرلەنوێ کارا دەبنەوە.

### ١٨. چۆنیەتی بەستنەوەی ڕاژەکاری ڤیدیۆ (Video Streaming Servers)
دەتوانیت هەر بەستەرێکی ڕاستەوخۆ (Direct MP4 URL)، بەستەری سێرڤەری تایبەتی ستریمینگ (HLS / m3u8)، یان CDN بۆ فیلمەکان دابنێیت لە خانەی کوالیتییەکاندا (1080p, 720p, 480p, 360p) بەبێ ئەوەی لۆدی قورس بخەیتە سەر ماڵپەڕەکە.

### ١٩. چۆنیەتی بەرزکردنەوەی وێنەی پۆستەر و باکدراپ
دەتوانیت وێنەکان لە Firebase Storage، Imgur، Cloudinary یان سێرڤەری خۆت دابنێیت و تەنها URL ەکەیان کۆپی بکەیتە ناو فۆڕمی فیلمەکە لە کاتی زیادکردندا.

### ٢٠. چۆنیەتی بڵاوکردنەوەی ماڵپەڕ لەسەر ئینتەرنێت (Deployment)
بۆ بڵاوکردنەوە لەسەر Firebase Hosting:
```bash
npm install -g firebase-tools
firebase login
firebase init hosting
firebase deploy
```
یان بە سادەیی فۆڵدەری پڕۆژەکە لەسەر GitHub Pages، Vercel، یان هەر هۆستینگێکی cPanel دابنێ.
